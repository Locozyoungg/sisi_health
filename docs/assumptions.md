# Assumptions

Every assumption that affects safety, privacy, cost, or the database is
recorded here before it is coded. Each entry: date, phase, decision made,
reason, and who must confirm it.

| A37 | Comparison-report price-sheet values (`SISI_AI_PRICE_*`, USD per 1,000 tokens) are PLACEHOLDERS (0.0) — cost per 1,000 conversations is computed but zero until real provider pricing is entered at H15. | We never invent pricing (non-negotiable 9). | Maintainer / H15. |
| A38 | Minor sexual-health two-step, replacing the plain hard gate for sexual-health questions (maintainer decision 2026-10-16). For a minor (age < 18 or unknown) asking a sexual-health question (sex, painful sex, intercourse, body questions about sex): with the answer unknown, `/ask` returns a deterministic per-language check question (`age_gated_minor`, zero model calls, no citations) and the app re-asks with `minor_has_sex`; `false` returns generic guidance without sexual content plus the nurse-referral line; `true` proceeds as retrieval + LLM education (routing `education`, citations intact) with the same deterministic nurse-referral sentence appended AFTER the post-filter, so the filter only ever judges model text. 18+ procedure topics (abortion, sterilisation, IVF, HRT, surrogacy) stay HARD-gated for every minor, whatever the answer. `minor_has_sex` is contract-only (never an identifier) and ignored for adults. Guardrail data: ai-151..156; wording in `MINOR_SEX_CHECK_TEXTS` / `MINOR_NO_SEX_TEXTS` / `MINOR_YES_NURSE_LINE`. | A hard gate left a pregnant teenager with no guidance at all, while most minors asking about sex are not sexually active: the two-step keeps the topic 18+-shaped for them and never makes a minor's question a dead end. | Maintainer (recorded 2026-10-16); clinician at H7 sign-off. |
